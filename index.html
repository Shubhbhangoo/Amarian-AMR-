THE IDEA

Money should be
verifiable by anyone.

Amarian is an independent engineering project. Its rules live in code, its supply is deterministic, and its consensus boundary is deliberately small.

PROTOCOL / THE RULES

Simple rules.
Hard boundaries.

Consensus is where Amarian becomes objective. Every node can derive the same answer without trusting a coordinator.

01 / SCARCITY01
AMR8.4M

Fixed issuance.

10 AMR begins the schedule. Rewards decay by 7/8 every 105,000 blocks. No premine, tail emission or mint authority.

02 / WORK02
300SEC

Proof of work.

SHA-256d secures the chain with difficulty targeting a five-minute block interval.

03 / MONEY03
10¹⁰

Integer money.

Every value is represented in facets. Floating point never enters consensus arithmetic.

04 / CRYPTO04
PQ

Built to migrate.

Explicit algorithm identifiers make cryptographic migration a protocol property, not an emergency rewrite.
