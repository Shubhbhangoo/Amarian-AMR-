01
PROTOCOL / THE RULES

Nothing hidden.
Nothing hand-waved.

Consensus is intentionally narrow. Nodes independently derive validity from deterministic rules instead of trusting a central authority.

01 / SCARCITY8.4M

AMR target

83,999,999,932,170,000 facets as the realised maximum supply. No premine, tail emission or mint authority.

02 / WORK300s

Block target

Bitcoin-derived SHA-256d proof of work secures the chain with difficulty targeting a stable five-minute interval.

03 / MONEY10¹⁰

Facets per AMR

Money is represented entirely as integer base units. Floating point never enters consensus arithmetic.

04 / CRYPTOPQ

Agility by design

Spend conditions carry explicit algorithm identifiers, making cryptographic migration a protocol property.

ARCHITECTURE / THE CORE

The boundary
is the security.

Consensus cannot reach storage, networking, wallet or RPC. The dependency direction is part of the design.
