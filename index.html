01 / PROTOCOL

Small rules.
Hard guarantees.

Amarian keeps consensus deliberately narrow. Every node independently derives what is valid from deterministic rules.

01

Fixed supply

Exactly 83,999,999,932,170,000 facets are the realised maximum supply. No premine, tail emission or mint authority.

8.4M AMR target
02

Proof of work

Bitcoin-derived SHA-256d secures the chain. Difficulty targets are selected for stability rather than novelty.

300s target interval
03

Integer money

All monetary values are integer base units. Floating point never enters consensus arithmetic.

1 AMR = 10¹⁰ facets
04

Quantum-aware

Spend conditions carry explicit algorithm identifiers from the first block, making cryptographic agility a protocol property.

Scheme registry
